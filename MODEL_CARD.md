## Established public description

K-DRUM is a physically based, grid-scale distributed hydrologic model developed by K-water. Published studies describe distributed rainfall-runoff simulation, radar/grid rainfall, kinematic-wave routing, Green-Ampt infiltration, surface/subsurface runoff, MPI parallelization, long-term runoff and snow-related applications.

## Current development extensions

- 1D dynamic-wave river-network hydraulics
- bidirectional 1D-2D coupling
- 2D flood-inundation analysis
- hydraulic-structure and reservoir-operation extensions
- high-resolution channel/terrain processing
- NetCDF-centered output integration
- InputStudio project authoring
- FloodViewer visualization
- experimental Estuary2DV salinity/hydrodynamics research
