K-DRUM은 분포형 수문·수리 모형을 통해 자연계의 물과 물질 순환을 디지털로 해석합니다. 시각자료는 주요 기능을 영상과 발표자료 이미지로 구성한 개요입니다.K-DRUM represents natural water and material movement through distributed hydrologic and hydraulic modeling. The Visual Guide presents an overview of its capabilities through a video and presentation images.

1D–2D·다중해상도

함께 확인할 내용 단방향과 양방향 연계는 서로 다른 방식입니다. 관심영역(Patch)은 원지형 해상도를 유지하고 배경 격자를 묶는 방식이며, 입력자료보다 세밀한 지형정보를 새로 만들지는 않습니다. 기능 설명 →

결과·물수지

함께 확인할 내용 출력 파일마다 격자와 저장 시각이 다를 수 있습니다. 1D–2D 교환 물수지, 유역 전체 물수지 폐합, 관측자료와의 비교는 서로 다른 평가 항목입니다. 기능 설명 →

통합 범위

함께 확인할 내용 전체 통합 그림은 연구·개발 방향을 포함합니다. D층은 완전한 지하수유동 모형과 다르며, Estuary2DV는 별도 실험 모형입니다. 기능 설명 →

About the introduction materials

2026-09-20 · A few expressions in the introduction materials may differ from the current website descriptions or scope. Notes for six items are provided below. The original PDF, video and images are preserved.

Read notes for six items

Snow processes

Read with this note Slope, D8 flow direction and time of day adjust an empirical melt factor. This is not a direct radiation-energy-balance or snow-transport calculation. Capability details →

HotStart

Read with this note Saved-state coverage can differ by enabled function; not every hydraulic extension is restored by the same saved state. Capability details →

Subbasin calibration

Read with this note Distinguish multi-site reporting and diagnostics from target-site calibration; this does not imply simultaneous automatic calibration of every subbasin. Capability details →

1D–2D and multi-resolution

Read with this note One-way and two-way coupling are distinct modes. Patches retain source-terrain resolution while background cells are grouped; no terrain detail beyond the input is created. Capability details →

Outputs and water balance

Read with this note Meshes and output times may differ by file. Exchange balance, watershed closure and observational fit are separate assessments. Capability details →

Integration scope

Read with this note The integrated overview includes research and development directions. The D-layer is not a complete groundwater solver, and Estuary2DV is a separate experimental model. Capability details →
