자주 묻는 질문

K-DRUM은 어떤 모형인가요?

K-DRUM은 K-water가 개발한 물리적 기반의 격자단위 분포형 강우유출모형입니다. 유역을 격자로 나누고 강우, 침투, 지표·지표하 유출과 하천 흐름을 계산합니다. 현재는 유역 수문과 하천·범람원 수리를 연계하는 방향으로 개발하고 있습니다. 공식 영문 명칭은 K-water Grid-based Distributed Rainfall rUnoff Model입니다.

K-DRUM의 주요 입력자료와 산출물은 무엇인가요?

기본 입력은 강우 시계열과 지형·토지피복·토양 등 격자 수문자료입니다. 장기·융설 모의에는 기상자료와 초기상태가 필요하며, 수리 확장에는 하천 단면·구조물·경계조건 등이 추가됩니다. K-DRUM은 유출량과 수문상태, 물수지·소유역 리포트를 제공합니다. 수위·침수심·유속 등 수리 결과와 NetCDF 통합출력의 제공 범위는 해당 기능의 개발 상태와 사용 버전에 따라 달라집니다.

확립된 기능과 개발 중인 기능은 어떻게 구분하나요?

2026-08-21 공개 검토 기준으로 격자 강우유출, Green-Ampt 침투, 운동파 추적, 장기유출·적설·융설과 MPI 연구 기반은 ESTABLISHED입니다. 1D 동역학파 하천망, 2D 범람, 구조물·댐 운영은 ACTIVE DEVELOPMENT입니다. 양방향 1D-2D 교환은 통제된 시험에서 확인된 VALIDATED DEVELOPMENT이며 모든 유역의 적용 인증을 뜻하지 않습니다. 유사·추적자는 RESEARCH FUNCTION, 수질 코드는 DISABLED / REDEVELOPMENT CANDIDATE입니다.

K-DRUM의 배포 경로와 버전 범위는 무엇인가요?

K-DRUM은 K-water 기술 SW 대국민 개방정책에 따라 MyWater 물정보포털의 K-Series에서 무료로 제공됩니다. 실제 배포 버전과 사용조건은 MyWater의 최신 안내와 이용약관을 기준으로 합니다. 현재 Core 개발 계열은 v3.x이며, MyWater 배포본의 기능 범위와는 차이가 있을 수 있습니다. K-DRUM 공개 저장소는 생산용 소스코드를 배포하지 않습니다.

소개 영상과 개념도는 실제 K-DRUM 계산 결과인가요?

소개 영상은 물순환과 디지털 해석을 설명하는 AI 개념영상이며 실제 K-DRUM 수치모의 결과가 아닙니다. 개념도는 계산 구조와 결과의 의미를 설명하는 자료입니다. 영상과 개념도에 표현된 과정 자체는 기능의 출시 여부나 검증 수준을 나타내지 않습니다. 각 자료의 표시와 개발 현황에 기능 상태가 명시되어 있습니다.

Core, InputStudio, FloodViewer와 Estuary2DV는 어떤 관계인가요?

Core는 계산 엔진, InputStudio는 프로젝트 입력 작성·점검 도구(ACTIVE DEVELOPMENT), FloodViewer는 지도·시계열 결과 분석 도구(RELEASE CANDIDATE)입니다. NetCDF 통합출력은 ACTIVE DEVELOPMENT입니다. Estuary2DV는 하구 흐름·염분을 다루는 별도 EXPERIMENTAL 연구모형입니다. 1D River Hydraulics Results Viewer도 별도 개발 중이며 아직 공개 GitHub 저장소에 게시되지 않았습니다.

Frequently asked questions

What is K-DRUM?

K-DRUM is a physically based, grid-distributed rainfall-runoff model developed by K-water. It represents a watershed as cells and calculates rainfall response, infiltration, surface/subsurface runoff and channel routing. Current development extends toward integrated watershed hydrology and river/floodplain hydraulics. Its canonical full name is K-water Grid-based Distributed Rainfall rUnoff Model.

What are K-DRUM's main inputs and outputs?

Core inputs include rainfall time series and grid-based terrain, land-cover and soil data. Long-term and snow simulations also use weather data and initial states; hydraulic extensions require river sections, structures and boundary conditions. K-DRUM provides runoff and hydrologic states, with water-balance and subbasin reports. Hydraulic outputs such as water level, flood depth and velocity, and integrated NetCDF output, depend on the version and development status of the relevant feature.

Which capabilities are established, and which are still in development?

As reviewed on 2026-08-21, grid-based rainfall runoff, Green-Ampt infiltration, kinematic routing, long-term runoff, snow processes and the published MPI lineage are ESTABLISHED. Dynamic-wave river networks, 2D flooding, structures and dam operation are ACTIVE DEVELOPMENT. Two-way 1D-2D exchange is VALIDATED DEVELOPMENT within controlled testing, without certification for every basin. Sediment and tracers are RESEARCH FUNCTION; water-quality code is DISABLED / REDEVELOPMENT CANDIDATE.

Where is K-DRUM distributed, and which version does it cover?

K-DRUM is available through MyWater K-Series under K-water's public software access policy, free of charge subject to the published terms. The actual download version and conditions of use are defined by MyWater's current information and terms. The current Core development line is v3.x; its feature scope may differ from the MyWater download. The K-DRUM public-information repository does not publish production source code.

Are the introductory video and concept diagrams actual K-DRUM results?

The introductory video is an AI-generated concept visualization of the water cycle and digital modeling, not a K-DRUM numerical simulation result. Concept diagrams describe model structure and the meaning of results. Illustrated processes do not establish release availability or validation. Each asset's label and the development status specify the relevant capability status.

How do Core, InputStudio, FloodViewer and Estuary2DV relate?

Core is the simulation engine. InputStudio supports project authoring and input checks (ACTIVE DEVELOPMENT); FloodViewer analyzes results through maps and time series (RELEASE CANDIDATE). Integrated NetCDF output remains ACTIVE DEVELOPMENT. Estuary2DV is a separate EXPERIMENTAL estuary hydrodynamics/salinity model. The 1D River Hydraulics Results Viewer is also developed separately and is not yet public on GitHub.

기능 상태 기준은 2026-08-21 공개 검토입니다. DEVELOPMENT_STATUS 및 Model Card에 기능별 범위와 개발 상태가 명시되어 있습니다.
