자주 묻는 질문

K-DRUM은 어떤 모형인가요?

K-DRUM은 K-water가 자체 개발한 물리적 기반의 격자단위 분포형 강우유출모형입니다. 격자별 강우·침투·증발산·적설·층별 저장·유출을 계산하고 하천망으로 전달합니다. 현행 계산엔진에는 개발 완료된 1D 하천수리, 2D 범람과 양방향 연계가 포함되어 유역에서 하천·범람원까지 연결해 해석합니다. 공식 영문 명칭은 K-water Distributed Rainfall-runoff Model입니다.

K-DRUM의 주요 입력자료와 산출물은 무엇인가요?

강우와 DEM·토지피복·토양·토심, 기상·초기상태가 유역 수문 입력입니다. 1D 수리는 하천 연결·횡단면·조도·경계·구조물 자료를, 2D 범람은 수리 지형·격자·경계·교환 위치 자료를 사용합니다. 산출물은 유량·수위·토양수분·증발산·적설·물수지, 수심·유속·침수 범위와 시간 변화입니다. 실제 기록 변수와 저장 간격은 선택한 계산 방식과 출력 설정에 따릅니다.

완료된 기능과 개발·연구 기능은 어떻게 구분하나요?

2026년 10월 28일 기준으로 1D 하천망 수리, 분기·합류, 2D 국부관성 범람과 양방향 1D–2D 연계는 개발 완료 기능입니다. Full SWE는 지원 조건에 맞춰 선택하는 완료 기능입니다. 강우유출·침투·적설·융설은 확립되어 있으며, 물수지·상태 저장·출력·구조물 기능도 구현되어 있습니다. GUI 도구 개발, 유사·추적 연구, 하구 실험모형과 비활성 수질 모듈은 별도로 표시합니다. 개발 완료, 유역별 적용 검증과 MyWater 공식 배포는 서로 다른 상태입니다.

K-DRUM의 배포 경로와 버전 범위는 무엇인가요?

이 홈페이지는 K-DRUM v3.x 계열의 기술 개발 현황과 주요 기능을 소개하며 실행파일을 직접 배포하지 않습니다. 공식 프로그램은 MyWater K-Series 배포 목록에서 K-DRUM을 찾아 다운로드할 수 있으며, 이용조건과 실제 배포 버전은 MyWater의 최신 안내를 확인해야 합니다. 개발·시험 기능은 공식 배포본과 포함 범위 및 업데이트 시점이 다를 수 있습니다.

소개 영상과 개념도는 실제 K-DRUM 계산 결과인가요?

소개 영상은 물순환과 디지털 해석을 설명하는 AI 개념영상이며 실제 K-DRUM 수치모의 결과가 아닙니다. 개념도는 계산 구조와 결과의 의미를 설명하는 자료입니다. 영상과 개념도에 표현된 과정 자체는 기능의 출시 여부나 검증 수준을 나타내지 않습니다. 각 자료의 표시와 개발 현황에 기능 상태가 명시되어 있습니다.

K-DRUM 계산엔진, InputStudio, FloodViewer와 Estuary2DV는 어떤 관계인가요?

K-DRUM Core는 유역 수문·1D 하천수리·2D 범람·양방향 연계를 계산합니다. 기존 InputStudio는 입력자료·프로젝트 구축을 담당하며 새 K-DRUM Studio는 프로젝트·제어·실행·분석을 통합하는 별도 개발 작업입니다. FloodViewer와 1D Viewer는 각각 평면·시계열 및 종단·횡단 결과분석 도구로, 엔진 개발 완료와 도구 공개 상태는 구분됩니다. NetCDF는 이미 사용하는 결과 저장 형식이고 Estuary2DV는 독립 하구 연구모형입니다.

Frequently asked questions

What is K-DRUM?

K-DRUM is K-water’s physically based grid-distributed rainfall–runoff model. It computes cell rainfall, infiltration, ET, snow, layered storage and runoff and routes water to rivers. The current engine includes completed 1D river hydraulics, 2D inundation and bidirectional coupling from watershed to river and floodplain. Its official English name is K-water Distributed Rainfall-runoff Model.

What are K-DRUM's main inputs and outputs?

Hydrology inputs include rainfall, DEM, land cover, soils/depth, meteorology and initial states. 1D hydraulics uses connectivity, sections, roughness, boundaries and structures; 2D flooding uses hydraulic terrain/grids, boundaries and exchange locations. Outputs include flow, stage, soil water, ET, snow, balance, depth, velocity and inundation evolution. Recorded variables and intervals follow solver/output settings.

How are completed capabilities distinguished from tools and research in progress?

As reviewed on October 28, 2026, 1D river networks, junction hydraulics, 2D local-inertial inundation and bidirectional 1D–2D exchange are development-complete. Full SWE is complete for supported configurations. Core hydrology, infiltration and snow are established; balance, state/output and structure functions are implemented. GUI development, sediment/tracer research, experimental estuary work and disabled water quality are identified separately. Completion is distinct from basin-specific validation and MyWater distribution.

Where is K-DRUM distributed, and which version does it cover?

This website explains the K-DRUM v3.x development line and its technical capabilities; it does not directly distribute executables. The official program is listed through MyWater K-Series, where users should check the current K-DRUM package and usage terms. Development and test features may differ from the officially distributed version.

Are the introductory video and concept diagrams actual K-DRUM results?

The introductory video is an AI-generated concept visualization of the water cycle and digital modeling, not a K-DRUM numerical simulation result. Concept diagrams describe model structure and the meaning of results. Illustrated processes do not establish release availability or validation. Each asset's label and the development status specify the relevant capability status.

How do the K-DRUM simulation engine, InputStudio, FloodViewer and Estuary2DV relate?

K-DRUM Core computes watershed hydrology, 1D hydraulics, 2D flooding and two-way exchange. Existing InputStudio prepares inputs/projects; new K-DRUM Studio is separate integrated project/control/run/analysis development. FloodViewer and the 1D Viewer interpret plan-view/time-series and profile/section results; engine completion and tool-release status are distinct. NetCDF is an implemented output format; Estuary2DV is independent estuary research.

기능별 구현·적용 범위는 2026-10-28에 검토했습니다. 1D 하천수리와 2D 범람의 개발 완료, 유역별 검증 및 공식 배포 여부를 별도로 안내합니다. DEVELOPMENT_STATUS 및 Model Card에 기능별 범위와 개발 상태가 명시되어 있습니다.
