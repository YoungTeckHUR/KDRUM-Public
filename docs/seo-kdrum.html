K-DRUM

K-water Distributed Rainfall-rUnoff Model · K-water 분포형 강우유출모형

K-DRUM은 K-water에서 개발한 물리 기반의 격자형 분포형 수문모형입니다. 강우, 융적설, 증발산, 토양 침투, 지표 및 지표하 유출과 하천 흐름을 공간적으로 해석하며, 공개 페이지에서는 현재의 Core 기능과 개발·연계·연구 기능을 구분하여 소개합니다.

주요 검색어와 기술 범위

K-DRUM, K-water K-DRUM, 분포형 강우유출모형, 분포형 수문모형, grid-based distributed hydrologic model, rainfall-runoff model, watershed hydrology, river hydraulics, flood analysis.

공개 자료

모형 개요와 기능 설명, 개발 상태, 발표자료 PDF, 기능별 참고 이미지와 모형 소개용 AI 개념영상을 공개합니다. 영상은 실제 K-DRUM 수치모의 결과가 아니라 모형 개념 설명용 시각자료입니다.
