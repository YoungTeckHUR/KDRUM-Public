# K-DRUM branding assets

This folder is the canonical public location for K-DRUM homepage branding assets.

- `kdrum-symbol-approved.png`: approved full K-DRUM symbol artwork, web-normalized raster copy.
- `kdrum-symbol-web.png`: homepage/hero use.
- `kdrum-symbol-compact.png`: small navigation/icon use.
- `kwater-official-ci.png`: K-water official CI asset used on the public homepage.

## Usage rules

1. Do not crop the K-DRUM symbol artwork.
2. Use `object-fit: contain` for rendered K-DRUM images.
3. Keep the full brush-like river tail, rainfall marks, and outer grid corners visible.
4. The K-water CI is a supporting institutional mark and should remain visually smaller than the K-DRUM identity.
5. Homepage asset references should point to this folder rather than temporary or legacy image paths.

The original higher-resolution review package was separately supplied to the project owner before homepage integration. The files in this folder are the normalized public web copies used for deployment.
