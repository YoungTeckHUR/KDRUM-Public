# K-DRUM homepage technical descriptions

The Korean homepage explainer cards use research-report-style technical descriptions. The descriptions are separated by section into `tech-features.js`, `tech-architecture.js`, `tech-functions.js`, `tech-research.js`, `tech-platform.js`, and `tech-resources.js` so that each topic can be revised independently as model development and validation progress.

The text distinguishes established model concepts, functions under development or validation, research applications, and supporting platform tools. Detailed custom illustrations will progressively replace the temporary concept panels.
