# K-DRUM homepage technical method notes

The Korean homepage explainer modal presents each topic using a consistent technical structure: technical description, key inputs, key calculations, major outputs, governing or representative equations, physical interpretation, application cautions, references, and an explainer image.

Equations labeled as representative concepts are intended to explain the physics or data flow and are not a claim that every displayed expression is the exact discretized equation used in every current K-DRUM code path. Development and validation status should be checked together with `DEVELOPMENT_STATUS.md` and `MODEL_CARD.md`.

K-DRUM-specific research references are drawn from `PUBLICATIONS.md`; standard hydrologic and hydraulic methods are accompanied by established methodological references.
