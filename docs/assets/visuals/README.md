# K-DRUM Homepage Visuals

This folder contains approved public-facing technical visuals used by the K-DRUM website.

## Approved watershed hero

- `kdrum-watershed-hero-approved.jpg`: approved homepage hero visual.
- Content: Korean-style mountainous watershed, computational grid, distributed rainfall/runoff, tributary convergence and main-river routing.
- The image is intentionally free of K-water logos, K-DRUM text, buttons and other embedded branding so that branding remains controlled by the website HTML.
- Do not add generated text or logos into this image when preparing web variants.
