# K-DRUM homepage technical popup guide

The Korean homepage popup cards are structured as compact technical notes rather than promotional captions. Each topic presents:

1. technical description;
2. public maturity/status label;
3. key inputs, calculations, and outputs;
4. governing or representative equations;
5. physical/conceptual interpretation;
6. key symbols and terminology;
7. application and interpretation cautions;
8. selected references and related K-DRUM research; and
9. links to current public documentation.

Some equations are representative conceptual equations for interpretation and are not a disclosure of unpublished K-DRUM numerical implementation details. Public maturity labels follow `DEVELOPMENT_STATUS.md` where a direct mapping exists; research/application and documentation cards are labeled conservatively when they are not standalone solver capabilities.
