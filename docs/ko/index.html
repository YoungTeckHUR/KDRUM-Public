K-DRUM

K-water Grid-based Distributed Rainfall rUnoff Model

K-water가 개발해 온 물리적 기반의 격자형 분포형 수문모형으로, 현재는 유역 반응에서 하천 수리와 범람원 해석까지 연결하는 통합 플랫폼으로 확장되고 있습니다.

K-DRUM의 수문 핵심기능은 홍수유출, 장기유출, 융설, 가뭄, 병렬계산, 지표수-지하수 연계 등의 공개 연구성과를 통해 축적되어 왔습니다. 현행 v3.x 체계에서는 그 기반 위에 새로운 수리·범람·입력편집·시각화 기능을 확장하되, 기능별 개발 성숙도를 구분하여 공개합니다.

모형 구조 보기공개 연구성과개발 현황
격자형 분포 물리과정공간 강우, 침투, 지표·지표하 유출과 흐름추적을 격자 단위로 해석합니다.
홍수사상부터 장기해석홍수유출과 함께 장기유출, 융설, 가뭄, 물수지 연구에 활용되었습니다.
병렬계산 연구 기반MPI 병렬화 연구성과와 대유역 계산 확장 계보를 갖고 있습니다.
v3.x 통합 확장하천수리, 1D-2D 교환, 범람해석, 입력작성과 결과 시각화를 연결합니다.

K-DRUM의 기술적 정체성

다른 모형과의 우열을 주장하기보다, 공개 연구성과로 확인할 수 있는 K-DRUM 자체의 특징을 중심으로 설명합니다.

공간 분포형유역 전체를 하나의 집중형 단위로 보지 않고 격자별 공간 반응을 해석합니다.
물리적 기반침투, 유출, 흐름추적과 물수지 과정을 물리적 개념과 식으로 구성합니다.
다중 시간규모단일 홍수사상뿐 아니라 장기 수문·융설·가뭄 분석에도 적용되어 왔습니다.
수문에서 수리로 확장v3.x는 확립된 수문 핵심을 하천과 범람원 해석으로 연결하는 개발 계보입니다.

강우에서 결과 해석까지

현재 플랫폼은 서로 분리된 파일 모음보다 하나의 연결된 모형 작업흐름을 지향합니다. 아래 흐름은 정보 구조를 설명하며 기능 성숙도 자체를 의미하지는 않습니다.

ESTABLISHED

분포형 수문 핵심

격자형 강우유출, 공간강우, Green-Ampt 침투, 지표·지표하 유출, 운동파 추적, 장기수문, 융설 적용과 MPI 연구 계보는 공개 연구성과가 축적된 기능입니다.

ACTIVE DEVELOPMENT

하천수리와 2D 범람해석

단면 기반 1D 동역학파 하천망, 수리구조물, 2D 범람해석과 통합 수리출력은 지속적인 QA와 검증을 수행 중입니다.

VALIDATED DEVELOPMENT

양방향 1D-2D 교환

통제된 개발 검증에서 하천과 범람원 사이의 양방향 교환이 실제 작동하고 시험 구성의 교환량 회계가 내부적으로 일관됨을 확인했습니다.

RELEASE CANDIDATE

전체 성숙도와 해석 범위는 DEVELOPMENT_STATUS.md에 정리되어 있습니다.

현재 기능 설명을 읽는 방법

기존 분포형 수문 기능은 공개 연구성과를 근거로 설명합니다. 새로운 하천수리, 1D-2D, 2D, 입력편집 및 시각화 기능은 현재 개발 성숙도에 맞춰 표현하며, 통제된 개발 검증을 모든 유역에 대한 생산 인증으로 확대 해석하지 않습니다.

K-water 및 연구 맥락

K-DRUM은 K-water MyWater의 K-Series 기술 소프트웨어 맥락에서 소개되고 있습니다. 기관 관련 정보는 K-water 공식 홈페이지에서 확인하는 것을 원칙으로 합니다.

MyWater K-Series · K-water 연구원

이 페이지는 독립적인 공개 기술정보 페이지이며 K-water 공식 기관 홈페이지로 표시하지 않습니다.

공개 범위. 생산용 소스코드, 제한된 입력자료, 민감한 운영정보, 비공개 진단자료, 내부 검증 데이터셋과 미공개 수치 구현 세부사항은 배포하지 않습니다. 상단 그림은 실제 모형 결과가 아닌 중립적 개념도임을 명확히 표시합니다.
