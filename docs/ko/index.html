K-DRUM

K-water Grid-based Distributed Rainfall rUnoff Model

물리적 기반의 격자형 분포형 수문모형에서 유역 수문·하천 수리·범람해석을 연결하는 통합 모델링 플랫폼으로 확장되고 있습니다.

홍수유출, 장기수문, 융설, 가뭄, 병렬계산과 지표수-지하수 연구로 축적된 수문 핵심을 기반으로 현행 v3.x 개발을 이어가고 있습니다.

K-DRUM의 핵심 특징

공개 연구성과로 확인할 수 있는 K-DRUM의 기술적 성격을 네 가지로 요약합니다.

공간 분포형유역을 하나의 집중형 단위가 아니라 격자별 공간 반응으로 해석합니다.
물리적 기반침투, 유출, 흐름추적과 물수지 과정을 물리적 개념과 식으로 구성합니다.
홍수부터 장기수문홍수사상뿐 아니라 장기유출, 융설, 가뭄과 물순환 연구에도 적용되어 왔습니다.
수문에서 수리로 확장v3.x는 확립된 수문 핵심을 하천 수리와 범람원 해석으로 연결합니다.

ESTABLISHED

분포형 수문 핵심

격자형 강우유출, 공간강우, Green-Ampt 침투, 지표·지표하 유출, 운동파 추적, 장기수문, 융설 적용과 MPI 연구 계보는 공개 연구성과가 축적된 기능입니다.

ACTIVE DEVELOPMENT

하천수리와 2D 범람해석

단면 기반 1D 동역학파 하천망, 수리구조물, 2D 범람해석과 통합 수리출력은 지속적인 QA와 검증을 수행 중입니다.

VALIDATED DEVELOPMENT

양방향 1D-2D 교환

통제된 개발 검증에서 하천과 범람원 사이의 양방향 교환과 시험 구성의 교환량 일관성을 확인했습니다.

RELEASE CANDIDATE

FloodViewer

통합 결과 뷰어는 현재 릴리스 후보 단계이며 최종 공개 1.0 제품으로 표현하지 않습니다.

전체 성숙도는 DEVELOPMENT_STATUS.md에서 확인할 수 있습니다.

공개 연구성과로 확인되는 활용 분야

홍수유출·레이더 강우

병렬계산

분포형 강우유출 계산의 MPI 병렬화와 계산 확장 연구.

지표수·지하수 연계

K-DRUM과 지하수 모형을 연결하는 연구와 적용성 평가.

산불피해 후 극한호우가 이어진 조건에서의 유출 반응 분석.

기능 설명 원칙

기존 분포형 수문 기능은 공개 연구성과를 근거로 설명하고, 새로운 하천수리·1D-2D·2D·입력편집·시각화 기능은 현재 개발 성숙도에 맞춰 표현합니다.

K-water 및 연구 맥락

K-DRUM은 K-water MyWater의 K-Series 기술 소프트웨어 맥락에서 소개되고 있습니다.

MyWater K-Series · K-water 연구원

이 페이지는 독립적인 공개 기술정보 페이지이며 K-water 공식 기관 홈페이지로 표시하지 않습니다.

공개 범위. 생산용 소스코드, 제한된 입력자료, 민감한 운영정보, 비공개 진단자료, 내부 검증 데이터셋과 미공개 수치 구현 세부사항은 배포하지 않습니다.
