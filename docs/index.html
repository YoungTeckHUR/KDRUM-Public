K-DRUM

K-water Grid-based Distributed Rainfall rUnoff Model

A physically based, grid-distributed hydrologic model developed by K-water, now evolving into an integrated platform connecting watershed response, river hydraulics and floodplain analysis.

K-DRUM's established hydrologic lineage is documented through public research on flood runoff, long-term hydrology, snowmelt, drought, parallel computation and surface-water–groundwater studies. The current v3.x platform extends that foundation while keeping development maturity explicit.

Technical identity

The public record supports four characteristics that define K-DRUM without relying on comparative or marketing claims.

Spatially distributedWatershed response is represented on a grid rather than as a single lumped catchment.
Physically based processesInfiltration, runoff, routing and water-balance processes are represented through physical formulations.
Multi-timescale hydrologyThe model family has been used for both flood-event and long-term hydrologic applications.
Hydrology-to-hydraulics evolutionThe v3.x line is extending the established core toward connected river and floodplain simulation.

Capability maturity is stated explicitly

Established research capabilities and current development components are intentionally separated. Detailed boundaries are maintained in the public development-status table.

ESTABLISHED

Distributed hydrologic core

Grid rainfall-runoff, spatial rainfall forcing, Green-Ampt infiltration, surface/subsurface runoff, kinematic routing, long-term hydrology, snow applications and MPI lineage.

ACTIVE DEVELOPMENT

River hydraulics and 2D flood analysis

Cross-section-based 1D dynamic-wave networks, hydraulic structures, 2D inundation analysis and integrated hydraulic outputs remain under continuing QA and validation.

VALIDATED DEVELOPMENT

Bidirectional 1D-2D exchange

Controlled development tests demonstrated active two-way river-floodplain exchange and internally consistent exchange accounting in the tested configuration.

RELEASE CANDIDATE

FloodViewer

The integrated result viewer is at release-candidate maturity rather than being described as a final public 1.0 product.

See DEVELOPMENT_STATUS.md for the full public maturity table and interpretation limits.

Current platform components

The platform separates the simulation engine, project authoring, result interpretation and reusable research modules.

K-DRUM Core

Distributed hydrology and the current hydrologic-hydraulic simulation engine.

InputStudio

Project configuration, time series, geometry, scenarios, consistency checks and engine-input generation.

FloodViewer

Integrated visualization of spatial and time-varying hydrologic and hydraulic results.

ChannelBed

Reusable high-resolution terrain, river-geometry and virtual channel-bed processing.

Integrated outputs

NetCDF-centered result exchange supporting consistent analysis across the engine and viewer.

Estuary2DV

Independent experimental research prototype for longitudinal-vertical estuary hydrodynamics and salinity.
