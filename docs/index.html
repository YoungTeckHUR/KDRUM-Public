K-DRUM

K-water Grid-based Distributed Rainfall rUnoff Model

A physically based, grid-distributed hydrologic model developed by K-water, now evolving into an integrated watershed-to-floodplain modeling platform.

The established K-DRUM hydrologic core is supported by a public research record spanning flood runoff, long-term hydrology, snowmelt, drought, parallel computation and surface-water–groundwater studies. The current v3.x generation adds river hydraulics, 1D-2D exchange, flood analysis, project authoring and result visualization with separately documented maturity levels.

Model architecture at a glance

K-DRUM is organized as a connected modeling chain: meteorological forcing and spatial terrain feed the distributed hydrologic core, river networks route and transform flow, floodplain domains exchange water with rivers, and integrated outputs support analysis and visualization.

Forcing & terrainRainfall · meteorology · DEM
Distributed hydrologyInfiltration · ET · runoff
River networkKinematic / dynamic routing
Floodplain interaction1D-2D exchange · inundation
Results & interpretationIntegrated output · FloodViewer

Capabilities, with maturity shown explicitly

Established model-family functions are separated from current hydraulic and software-development tracks. The labels below summarize the public status table rather than implying uniform production readiness.

ESTABLISHED

Distributed hydrologic core

Spatial rainfall-runoff, Green-Ampt infiltration, surface and subsurface runoff, kinematic-wave routing, long-term hydrology and snow applications are supported by the public research record.

ACTIVE DEVELOPMENT

1D river hydraulics and 2D flood analysis

Cross-section-based dynamic-wave river networks, branched/confluence hydraulics, hydraulic structures and 2D inundation are under integration and verification.

VALIDATED DEVELOPMENT

Bidirectional 1D-2D coupling

Controlled development validation has demonstrated active two-way river-floodplain exchange in the tested configuration; this is not a basin-wide production certification.

RELEASE CANDIDATE

K-DRUM FloodViewer

The integrated result viewer is in release-candidate development, while InputStudio and other authoring/geometry tools remain active-development components.

For the full maturity table and validation boundary, see DEVELOPMENT_STATUS.md.

Current platform tools

The v3.x work is moving from file-by-file workflows toward a more consistent project, simulation and interpretation environment.

K-DRUM Core

Distributed hydrology and the current hydrologic-hydraulic simulation engine.

InputStudio

Project configuration, time series, geometry, scenarios, consistency checks and engine-input generation.

FloodViewer

Integrated spatial and time-varying visualization of hydrologic and hydraulic results.

ChannelBed

Reusable high-resolution terrain, channel-geometry and virtual channel-bed processing.

Integrated NetCDF outputs

Modernized exchange of simulation results between the engine and viewer.

Estuary2DV research prototype

Separate experimental work on longitudinal-vertical estuary hydrodynamics and salinity.
